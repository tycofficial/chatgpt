# ChatGPT Web

网站入口直接运行已保存的原版前端模块图。原版 React 组件、路由、模型选择器、编辑器和动画一起运行；浏览器宿主、账户存储、模型目录与对话服务通过明确的接口适配到本地浏览器及配置的 API。

网站：https://tycofficial.github.io/chatgpt/

## 源码与构建

- `original-client/public/`：原版公开静态资源，保留模块依赖和文件名。
- `src/native-client/`：可编辑的账户、宿主和 API 适配器源码。
- `native-client/`：带版本号的发布模块；`adapter-provenance.json` 记录来源。
- `native-client-worker.js`：将原版 `/cdn/assets/` 请求映射到 GitHub Pages 项目目录，保留模块关联。
- `index.html` / `404.html`：客户端入口和深链接入口。

```sh
npm run release:prepare
npm run native:check
npm start
```

本地地址为 `http://127.0.0.1:4400/chatgpt/`。构建只依赖仓库内的 `src/native-client`，不需要私人登录页面或浏览器 Cookie。

## 当前接口

Chat 与 Work 使用同一真实执行循环与本地会话存储。Chat 仅提供 GPT-6 和 GPT-5.6 Sol 两个家族，Pro 选项通过独立 reasoning.mode 请求并检查供应端回执。Work/Codex 保留八个已核对的手选模型及原默认精选六档；两款 Luna 从轻度到 Max，其余支持本站 Ultra 并行执行。模型显示目录和 API 合法参数分别校验。

快速模式使用原组件、粒子动画和原浏览器宿主 IndexedDB 偏好存储；当前网关没有已验证的 priority 能力，因此不会声称实际 API 获得加速。Sol/Astra 的 Ultra 是本站真实并行委派与工具循环，底层请求同一模型的 API max，不能等同于 OpenAI 私有 Ultra 后端。

“添加账户”使用本站用户名和密码。管理员可以在浏览器离线验证和恢复登录，只保存 PBKDF2 加盐摘要，不把本地会话冒充云端令牌；本站 Pro 不等于官网订阅授权。Free 只显示 Chat，隐藏模型、Work/Codex、Dot；其默认 Instant 使用 GPT-5.6 Luna，原加号菜单“思考一下”使用中等。Plus 不开放 Dot，Pro 才开放本地 Dot。

注册用户仍由独立 D1 服务验证和同步聊天文本。离线管理员的聊天保留在当前浏览器，不声称已跨设备同步。新分享链接用 URL 片段携带选定分支的文本快照，其他设备无需创建者存储即可读取；它不等于服务器保存，也不包含本机附件字节，仍要求接收者能访问网站。

新 API 优先承接其目录中准确支持的模型，旧 API 作为备用。明确额度耗尽、且未发生输出或工具副作用时才自动切换，不改模型或思考等级；认证、限流和普通错误不误报额度。流式思考状态和实际耗时传给原组件，耗时是本地观察的 API/任务用时，不是供应端内部纯思考时间。重新生成创建共享原问题的新答案分支，并保留旧答案和各分支上下文。

模型可以显式调用 `publish_file`，把当前对话浏览器工作区中的真实成品保存到资料库。每次编辑生成独立、不可变的原文件版本，保持资料库身份、文件夹、自定义名称与收藏。原“生成的文件”筛选与下载菜单读取实际字节并核对 SHA；后台保存通过原 QueryClient 的资料库失效链更新列表。刷新页面后，会为已提交且本机仍可读取的文件重建下载资源，保留真实提交回执和缺失文件状态。

首次进入 Codex 时，原目录接口仅在没有保存过选择、且真实浏览器文件系统就绪时，使用唯一的浏览器工作区 `/mnt/data`。显式清空或已有项目选择保持原样。原数据管理的全部归档与删除操作写入当前账户的真实 Chat／Work 会话存储；Dot 和独立 Codex 线程不在批量操作范围。

连续任务采用 Responses 工具调用循环，保存实际工具结果与恢复检查点。模型明确标记为 `commentary` 的进度说明保留其阶段并继续执行；连续只有说明时最多续跑三轮，再明确保存为未完成，不把说明当成成果。未确认完成的流不执行其中的工具调用。刷新通过原版恢复协议续接，余额不足明确报错并保留进度。原上传卡片的文件实际保存在浏览器 OPFS/IndexedDB；文本和支持的图片可作为模型输入，完整文本可用工具分段读取。Python 使用 Pyodide WebAssembly；这不等于原版私有云执行环境。

PDF 和 DOCX 在专用 Worker 内用固定版本 PDF.js／Mammoth 提取真实文字，保留原始文件与经过 SHA 校验的 UTF-8 文本副本；长文字的后续读取使用文本副本路径。解析超时、取消、损坏、加密、没有可提取文字或存储额度不足会明确失败。页数或文字截断会标明范围；不声称已做 OCR、理解图片或读取未提取部分。其他 Office 格式目前仍明确不支持。解析器及所需字体、字符映射一同打包并记录哈希。

管理员可使用 `local-bridge/` 的独立本机通道，经本人完成官方 Sign in with ChatGPT 及订阅使用授权后转发真实 Responses 流；Free 账户仍使用配置的 API。本机离线时回到 API；已经接收的本机任务、订阅额度错误不会暗中重发或改用 API 计费。通道支持真实取消、最多三路并行和同一任务重连，不读取官网登录 Cookie，也不虚构订阅计划或剩余额度百分比。没有完成本人授权前，不会连接官方订阅额度。

`config.js` 提供本站默认 API 配置。原始登录捕获、会话凭据和私有诊断保留在被 Git 忽略的本地目录。

发布版本包括适配器、运行时、Python Worker 和资源的实际内容指纹。`native:check` 对照可编辑源码、发布代码、入口和资源哈希，发现未打包修改会失败。已打开页面会在对话空闲且没有未发送文字或附件时检查、加载完整新版；离线时保留现有页面。
